## `🧠 workflow.sh`

```bash
#!/bin/bash
# execute on every new project

run_workflow() {
  echo "[+] IDEA"        && sleep 1
  echo "[+]   -> DESIGN"
  echo "[+]     -> PROTOTYPE"
  echo "[+]       -> CODE"
  echo "[+]         -> POLISH"
  echo "[+]           -> SHIP"
  echo "[✓] process complete. 0 errors."
}

run_workflow
```

```diff
- design and development as separate jobs
+ one continuous process, end to end
```

I don't treat design and development as separate jobs.

The interface matters.  
The code matters.  
The tiny details matter too.
